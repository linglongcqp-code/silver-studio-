出图方式

第一步

上传同款实拍并确认品类、工艺和参数。调整每张分镜的提示词与参考图。

第二步

点击「交给 Codex 出图」，下载含实拍与提示词的任务文件。把文件上传到本聊天，告诉 Codex「用内置绘图按此任务生成」。也可以直接在聊天里上传实拍。

第三步

下载 Codex 生成的单张图片，回到这里点「导入成图」匹配分镜，再核对产品、制作参数页和打包下载。

调用边界

网页不能直接调用聊天内置绘图。这是网页整理、聊天出图、成图回填的协作流程，不会在网页后台自动生成。是否可用及使用额度以当前 Codex 账号为准。

可选 API

若以后需要网页直接批量出图，后端仍预留 OPENAI_API_KEY 与 OPENAI_IMAGE_MODEL 配置入口；密钥只在服务端保存。

内置绘图的画幅由任务说明约束。可选 API 模式的方图为1024×1024；竖图生成后会裁为3:4，请核对裁切是否保留完整产品。
PRODUCT FIRST

产品保真规则

01 保留造型、纹样、链节、配件和表面工艺，不补画未提供的细节。

02 背景使用低饱和、低对比色，少量道具，不遮挡或抢过产品。

03 同套使用统一色调和光线，白底图单独保持纯白。

04 佩戴比例参考真实尺寸；尺寸不明时不制作测量示意或编造数值。

05 生成结果对照原图审核，重点看轮廓、纹样、数量、银色和尺寸感。AI 无法保证完全一致。
