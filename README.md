# 银作 · 银饰电商组图工作台 V1.1

面向银饰的电商组图网页：上传实拍，规划8/9张分镜，填写背景元素、封面标题、细节说明，导出 Codex 内置绘图任务，再导入成图和制作参数页。

## 直接使用

下载仓库中的 `index.html`，用浏览器打开即可。这个文件已包含所需样式和脚本。

网页默认使用 **Codex 内置绘图协作**，无需在网页配置 API Key：

1. 上传同一款商品的各角度实拍，确认品类、工艺和参数。
2. 在“02 画面风格 → 背景与文案”填写背景元素、封面标题/副文案以及细节说明；空字段不添加文案。
3. 点击“交给 Codex 出图”，把下载的 JSON 上传到 Codex 聊天，并说“用内置绘图按此任务生成”。
4. 下载成图，在网页中导入对应分镜，核对造型、纹样和配件。
5. 本地制作参数页，再下载图片包与项目备份。

网页不能直接启动聊天中的内置绘图。标题或说明改变后，受影响的图片会标记待更新；已有图片需要重新出图才能采用新文案。白底图始终不加文案或道具。

## 发布到 GitHub Pages

仓库根目录的 `index.html` 和 `.nojekyll` 已准备好，可直接作为 Pages 发布内容。

1. 打开仓库 **Settings → Pages**。
2. 在 **Build and deployment → Source** 选择 **Deploy from a branch**。
3. 选择分支 **main**、目录 **/(root)**，点击 **Save**。
4. 等待 GitHub 显示发布成功，再使用该页面给出的实际网址。

此仓库的预期地址为 `https://linglongcqp-code.github.io/silver-studio-/`；该地址只在 Pages 实际启用并发布成功后可用。请保留仓库名称末尾的连字符。

GitHub Free 的 Pages 支持公开仓库；私有仓库是否可以启用取决于账号套餐。私有源码仓库的 Pages 网站也不一定是私密网站，发布前应确认可见范围。说明见 [GitHub Pages 文档](https://docs.github.com/en/pages/getting-started-with-github-pages/about-github-pages)。

## 项目与照片保存在哪里

项目、实拍和导入的成图保存在当前浏览器的 IndexedDB 中，本站没有云端同步服务。仓库仅包含程序源码和网页，不包含商品照片或出图任务。

**从本地文件切换到在线网址前，请先导出项目 JSON 备份，再到新网址导入。** 本地文件、localhost、在线网址分别使用自己的浏览器存储；换设备、换浏览器或清理站点数据后也需要重新导入备份。

## 修改与检查

需要 Node.js 22 或更新版本；无第三方运行依赖。

```sh
npm test
npm run build
npm run dev
```

`npm run build` 从 `src/` 重建仓库根目录 `index.html`。修改源码后，应将源码和重建的 `index.html` 一起提交。`npm run dev` 在 `http://127.0.0.1:4173` 启动开发服务器。

## 可选 API 模式

GitHub Pages 仅提供静态页面，不运行本仓库的服务端 API。Pages 版本请使用默认的 Codex 协作模式。

如以后需要网页直接出图，应另行部署服务端，并通过服务端环境变量配置 `OPENAI_API_KEY`。本地开发服务器读取进程环境，不自动加载 `.env`。密钥不应写入前端、项目导出或代码仓库。API 使用独立计费，当前默认流程不需要它。

## 产品核对

AI 图片需对照实拍检查细微纹样、形状与配件。程序不自动确认材质、纯度、重量或尺寸；未填写参数显示“待确认”。参数模板只作原图对照，参数页使用本地版式。
